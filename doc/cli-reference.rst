Command reference
=================

Every CNVkit subcommand and its options, as ``cnvkit.py <command> --help``
prints them. This page is generated from the program itself when the
documentation is built, so it always describes the release it ships with.

It is a reference, not a guide: it lists what each option is called and what it
defaults to, but not when to reach for it. The pages under :doc:`pipeline`,
:doc:`plots`, :doc:`reports` and :doc:`importexport` explain the commands in
the order an analysis uses them, and are the better starting point.
